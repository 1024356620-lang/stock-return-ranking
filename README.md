# 股票收益截面排序研究

基于个股量价特征预测未来收益排序，比较 GRU 的均方误差（MSE）与成对逻辑排序损失，并以 Ridge 回归、负换手率作为简单基线。研究采用年度滚动划分、多个随机种子和逐日配对检验，关注学习目标的增量效果及跨年份稳定性。

主要评价指标为逐日 Spearman Rank IC。现有结果中，排序损失的年度平均 IC 均高于 MSE，但差异未达到 5% 显著性水平；GRU 相对简单基线也未表现出稳定的跨年优势。项目评估的是预测排序能力，不包含扣除交易成本后的策略收益。

## 快速开始

在项目根目录安装依赖并查看结果：

```bash
python -m pip install -r requirements.txt
python project.py list
python project.py report
python project.py verify
```

- `list`：显示实验索引与完成状态。
- `report`：展示已发布的结果汇总。
- `verify`：使用已保存的逐日 IC 和汇总表核验配对关系、统计汇总及 HAC 结果，不重新训练或从原始行情生成预测。

上述命令无需行情数据或模型权重。训练及重新生成逐股票预测需要另行导入数据，见下方“数据准备”。完整命令见[运行指南](docs/PROJECT_GUIDE.md)，实验范围见[实验索引](docs/EXPERIMENT_INDEX.md)。

## 数据与研究设计

### 特征和标签

GRU 使用每只股票截至信号日的连续 60 条记录，每条记录包含 7 个特征：

| 特征 | 含义 |
|---|---|
| `ret_1d` | 相邻记录的收盘价收益率 |
| `ma5_dev` | 收盘价相对 5 条记录移动均价的偏离 |
| `ma20_dev` | 收盘价相对 20 条记录移动均价的偏离 |
| `log_vol_ratio` | 成交量相对 20 条记录移动均量之比的对数 |
| `turnover` | 换手率 |
| `amplitude` | 最高价与最低价之差除以当期收盘价 |
| `vol_20d` | 最近 20 条记录收益率的滚动标准差 |

标签为 `close.shift(-5) / close - 1`，即未来 5 条个股记录的收盘价收益；个股记录缺失时，不一定等于统一交易日历上的未来 5 个交易日收益。信号日须成交量、成交额均为正。该筛选不保证实际可成交，也不处理涨跌停交易约束。

GRU 的特征标准化参数在训练日期范围内拟合，Ridge 则在实际训练样本上拟合，均不使用验证或评价期拟合参数。GRU 输入窗口中的特征缺失值按股票前向填充，再以 0 填补剩余缺失。

### 年度划分

| 评价年份 | 训练期 | GRU 验证期 |
|---|---|---|
| 2023 | 2020—2021 | 2022 |
| 2024 | 2020—2022 | 2023 |
| 2025 | 2020—2023 | 2024 |

训练样本的标签结束日期须早于验证期，验证样本的标签结束日期须早于评价期；输入窗口可以包含分界日前已知的历史记录。模型及标准化参数按年重新拟合。Ridge 跨年比较采用相同训练年份，间隔年不加入拟合，也不用于逐年重新选择正则化参数。

GRU 采用均值池化，隐藏维度为 64，Dropout 为 0.2；使用 Adam，初始学习率为 0.001，权重衰减为 0.0001，梯度裁剪阈值为 1。每日抽样最多 100 只股票、至少 20 只，以验证集 Rank IC 调整学习率和早停，最多训练 50 轮，早停耐心值为 10。每个符合条件的日期在一轮训练中出现一次，日期顺序打乱。

正式排序损失对同日标签不相等的股票对计算 `softplus(-direction * score_diff)`。存在有效股票对时，常数预测的损失为 `ln(2)`。早期零间隔铰链损失允许常数预测取得零损失，其结果不作为正式比较依据。

## 实验结果

### GRU 学习目标比较

每年、每种学习目标使用 10 个随机种子。先计算各个种子的逐日 IC，再对种子和日期取平均；表中数值不是预测分数集成后的 IC。

| 评价年 | 天数 | MSE IC | 排序 IC | 排序 − MSE | HAC p 值 | 差值 Bootstrap 95% 区间 |
|---|---:|---:|---:|---:|---:|---|
| 2023 | 242 | 0.06152 | 0.06908 | +0.00756 | 0.3411 | [−0.00923, 0.02426] |
| 2024 | 237 | 0.04359 | 0.06719 | +0.02360 | 0.1798 | [−0.01353, 0.05819] |
| 2025 | 238 | −0.00481 | −0.00002 | +0.00479 | 0.6976 | [−0.01690, 0.03407] |

来源：[GRU 年度汇总](results/final/formal_gru.csv)。三年差值均为正，但 HAC 和 Bootstrap 检验均未达到 5% 显著性水平。2024 年虽然 10 个种子方向一致，它们仍共享同一段市场样本，不能视为 10 段独立的市场证据。早期 3 种子结果不替代本表的 10 种子结果。

### GRU 与简单基线比较

逐股票、逐日期取共同样本，核对收益标签后重新计算 IC。Ridge 使用信号日的特征，GRU 使用 60 条历史记录，因此这里比较的是完整预测方法，不是仅改变模型结构的消融实验。

| 方法 | 2023（237 天） | 2024（237 天） | 2025（238 天） |
|---|---:|---:|---:|
| GRU-MSE | 0.05808 | 0.04359 | −0.00481 |
| GRU 排序 | 0.06570 | 0.06718 | −0.00002 |
| 原始 7 特征 Ridge | 0.02706 | −0.02432 | 0.00265 |
| 删除振幅的 6 特征 Ridge | 0.04414 | 0.00052 | 0.02621 |
| 负换手率 | 0.05703 | 0.05012 | 0.00950 |

来源：[同样本模型汇总](results/final/common_sample_models.csv)、[配对检验结果](results/final/common_sample_comparisons.csv)。每年 6 项 GRU 与基线的比较，其原始 HAC 和 Bootstrap p 值均大于 0.05，年度内 Holm 校正后也未显著。没有一种方法在所有年份的平均 IC 都最高。

**2023 年两张表的来源和样本口径不同。** 正式 GRU 表使用原年度实验的 242 天结果，其脚本未限制评价样本的标签必须在年末前结束；同样本比较使用实验 A 中原始 7 特征基准组的重跑结果，并限制标签结束日期不超过年末，得到 237 天。两张表不能直接相减计算模型增量。

Ridge 跨年实验固定正则化系数 λ=10，优化目标为平均平方误差加 λ 乘权重平方和，截距不受惩罚。该 λ 与使用未归一化平方误差的 `sklearn.Ridge(alpha=...)` 数值口径不同。负换手率直接使用 `-turnover`，不拟合模型。

### 特征与训练窗口诊断

| 实验 | 评价范围 | 观察结果 |
|---|---|---|
| 原始 7 特征拼接 7 个截面排名特征 | 2023，两个目标各 10 种子 | MSE IC 变化 −0.05275，排序 IC 变化 −0.00760；均仅 1/10 种子改善 |
| Ridge 删除振幅 | 2022 验证集，λ=10 | IC 从 0.03347 升至 0.05041 |
| Ridge 删除振幅后跨年比较 | 2023、2024、2025 | 相对原始 7 特征的 IC 增量依次为 +0.01708、+0.02484、+0.02356 |
| 最近两年与扩展训练窗口比较 | 2023 验证集，排序目标，3 种子 | 最近两年 IC 为 0.07268，扩展窗口为 0.07419，差值 −0.00151 |

来源：[截面排名特征实验](results/final/A_2023.csv)、[Ridge 跨年结果](results/final/ridge_crossyear.csv)、[窗口诊断](results/final/window_validation.csv)。截面排名拼接的 2024 年实验未完成，不纳入结论。Ridge 候选由 2022 年验证结果筛选；窗口实验的验证集同时用于早停和方案比较。以上属于探索性分析，不能据此推断 GRU 删除振幅或缩短窗口必然有效。

## 统计口径与适用范围

每天在股票截面上计算 Spearman IC，再对日期等权平均。正式比较中，常数预测的 IC 记为 0，常数标签的 IC 记为缺失。学习目标比较先计算同种子、同日的 IC 差值，再对固定种子平均；与确定性基线比较时，先平均 GRU 各种子的逐日 IC，再减去基线的逐日 IC。

- HAC 使用 Bartlett 权重、滞后阶数 5 和正态双侧近似。
- 移动分块 Bootstrap 的块长为 10；正式学习目标比较重复 2,000 次，GRU 与基线比较重复 10,000 次。
- GRU 与基线比较报告每年 6 项检验的 Holm 校正；该校正不覆盖整个研究过程中的全部候选筛选。

这些检验回答的是平均 IC 差异是否偏离 0，不是单个模型自身 IC 是否显著大于 0。未达到显著性不等于两种方法等价，也不等于模型完全没有预测能力。HAC 与 Bootstrap 基于同一数据，不构成两次独立验证。

2023—2025 年结果均已被观察，后续在这些年份上调整方案仍属于探索性研究。原始股票池的历史成员、复权方式、退市覆盖及缺失交易日需要结合原始数据核验；现有结果不能据此排除幸存者偏差。项目未验证持仓构建、交易成本、滑点、流动性或容量，不能将 Rank IC 直接解释为可实现收益。

## 数据准备

仓库包含代码和结果 CSV，不分发行情数据、特征缓存、逐股票预测或模型权重。数据需由使用者按来源许可自行准备。

### 已有特征缓存

将原项目的 `seq_features.parquet` 导入当前项目。Windows 示例中的路径需替换为实际文件路径：

```bat
python project.py data --features "C:\path\to\ml\seq_features.parquet"
```

命令校验必要字段、股票日期键、标签结束日期等，并复制为项目根目录的 `seq_features.parquet`。它不会覆盖已有文件；源文件与目标相同时只校验。此检查不替代对数据来源和特征构建时点的核验。

### 只有原始行情

```bat
python project.py data --klines "C:\path\to\ml\klines.pkl"
python project.py build-features
```

`klines.pkl` 应为“股票代码 → pandas DataFrame”的字典。每张表需包含 `date`、`close`、`high`、`low`、`volume`、`amount`、`turn`；日期列须可解析，其余列须为数值。仅使用可信来源的 pickle 文件。

`build-features` 生成特征缓存，不训练模型。导入及构建命令拒绝覆盖已有数据；更换行情时应先备份并移除旧缓存，再重新构建。训练脚本优先读取现有缓存，不会自动根据新的行情刷新它。

| 路径 | 内容 |
|---|---|
| `project.py` | 结果查看、数据导入和脚本运行入口 |

后三项为本地运行数据，由 `.gitignore` 排除，不纳入版本控制。首次获取仓库时无需这些文件即可查看和核验已发布结果；重新训练则需要准备数据。
